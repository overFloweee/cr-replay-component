# 开源内容与验证边界

本仓库采用 Apache-2.0，源码公开已于 2026-10-23 获得项目所有者授权。源码提取自皇室营地产品 main `d815abb34bbb3847ca2fec95df3096059ea7dda0`，使用全新 Git 历史，并保留 FirstLight 的适用归属与 NOTICE。公开范围以本文、来源记录和已有构建证据为准；实际设备播放暂缓，不据此承诺示例已经通过播放验收。

## 定位与公开清单

这是一套针对固定《皇室战争》核心的 Android 回放接入和本地构建工具。它依赖使用者另行提供精确的游戏材料；当前未提供 AAR，也没有将游戏核心实现为独立模拟器。

| 目录或文件 | 开源内容 | 能力边界 |
| --- | --- | --- |
| `android/cn/crhistory/player/` | 回放入口、输入校验、版本与规则选择、原生启动协调、结果读取、独立进程与运行目录管理、本地资源准备、最小示例页面 | 保留产品 main 的接入机制；独立宿主的设备生命周期未验，不含营地业务服务 |
| `native/replay_bridge.cpp` | JNI、固定核心地址和结构偏移、短指令校验字节、Hook、回放提交、终局塔与皇冠观测、画面帧观测 | 面向一个精确登记的恢复核心；皇冠一致不能证明完整过程保真 |
| `tools/` | 完整构建入口、核心恢复、客户端启动路径修改、规则与视觉处理、资源归档与登记表生成 | 包含逆向适配和客户端修改实现；输入材料及生成物不随源码分发 |
| `example/AndroidManifest.xml` | 本地示例应用及私有回放进程的声明 | API 30+、arm64；没有配置账号或网络服务 |
| `metadata/` | 核心与材料身份、版本映射、规则登记、历史资源摘要 | 只有文件名、版本和摘要等登记信息，不包含官方规则 CSV 或游戏资源；有登记不等于所有对局准确 |
| `tests/` | 合成输入、版本与失败检查、规则/视觉包检查、资源边界、归档和终局算法检查 | 主机测试，不能代替 Android 实际播放或画面保真验收 |
| `docs/`、`LICENSE`、`NOTICE`、`licenses/` | 来源映射、构建与验收证据、材料要求、兼容限制和许可证归属 | 构建证据只记录摘要和状态，不附带生成的游戏客户端或真实回放 |

公开 Native 源码会公开具体地址、偏移和少量目标函数指令签名；公开构建工具会公开生成、修改客户端 smali 的方式。完整游戏二进制不进 Git，并不意味着这些实现细节被排除。这部分来源与分发边界见 [provenance.md](provenance.md)。

## 三个此前暂缓的脚本

| 文件 | 当前核查结论 | 外部材料及生成物 |
| --- | --- | --- |
| `tools/official_core.py` | 已核完整源码及项目 Git 来源；按原库、RX、符号和导出信息恢复精确登记核心，保留完整性断言并拒绝 Python 优化模式 | 原库、运行时转储、符号/导出材料及恢复后的 ELF 不进 Git |
| `tools/official_engine.py` | 已核完整源码及项目 Git 来源；解包 APK、组合快照、修改应用初始化与回放启动路径 | 解包后的游戏代码、修改后的客户端和 APK 保持本地 |
| `tools/replay_visuals.py` | 已核完整源码及项目 Git 来源；检查指定动画、SCDB 与依赖，只修改登记的资源记录 | 官方动画 JSON、SCDB、GLB 及生成的视觉覆盖包不进 Git |

这些脚本随源码一同公开。已核出的来源记录不等于所有底层知识都为独立原创，也不等于游戏权利人已授权材料获取、客户端修改或生成物分发。FirstLight 的适用归属保留；Apache-2.0 只覆盖贡献者有权许可的源码及适用的第三方许可部分。

## 不公开的内容

- 官方 APK、完整游戏核心、运行时转储与符号材料。
- 官方规则、图片、动画、声音、SCDB、GLB 和资源包。
- 真实回放、玩家数据、账号凭据、开发或正式签名私钥。
- 生成 APK、修改后的客户端树、恢复核心、规则/视觉包等本地产物。
- 皇室营地的账号、会员、云归档、后端、CDN 和运营配置。
- 后续研究分支的材料封存、信任机制、业务验收成果与原私仓历史。

## 可复现与验证范围

源码已经在本机已有的精确外部材料上完成构建，主机合成检查通过。克隆仓库可以阅读实现和执行合成测试；完整构建还需要 [materials.md](materials.md) 列出的 APK、十份引擎/内容输入和指定动画文件。仓库不提供这些材料的下载服务，也未补齐运行时转储的完整采集来源与采集流程。只取得一个公开 APK 仍不足以复现整个构建。

固定核心版本为 38.4.2，七套规则快照不代表七个独立核心。未知输入和未登记组合按当前合同拒绝；登记中的候选状态与既有别名保持原样，不扩展支持范围。兼容声明以 [compatibility.md](compatibility.md) 为准。

源码公开不改变“播放未验”的状态。未来若要声明可实际播放、可重复进出或过程准确，需要对应的设备证据。历史构建与审查记录保留其生成时的审批状态，不作为本次源码公开的状态记录。
